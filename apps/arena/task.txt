Python 3.11以上の標準ライブラリだけで、Redis互換の小さなインメモリKVサーバを実装してください。設計、実装、自動テスト、実行確認まで、この作業ディレクトリ内で自律的に完了してください。

起動方法:
  python3 server.py --port <port> --data <path>

要件:
- 127.0.0.1でTCP接続を受け付ける。
- --port 0ではOSが空きポートを割り当てる。
- 起動時、標準出力に「LISTENING <実際のポート番号>」を1行で出し、直ちにflushする。
- 入力はRESP2のbulk string配列とする。inlineプロトコルは不要。
- コマンド名はASCIIの大文字小文字を区別しない。
- キーと値は空文字列・改行・NUL・非UTF-8を含む任意のバイト列を扱える。

実装するコマンド:
- PING （引数なし）
- SET key value
- GET key
- DEL key （キー1つ）
- INCR key
- PEXPIRE key milliseconds
- PTTL key

動作:
- 上記の範囲でRedisと同じ応答形式・意味を実装する。エラーの文言一致は不要。
- SETで既存キーを上書きした場合、そのキーのTTLは解除される。
- 期限切れキーは存在しないものとして扱う。
- PTTLは存在しないキーに-2、期限なしのキーに-1を返す。
- PEXPIREは存在するキーに1、存在しないキーに0を返す。0以下の期間は即時削除する。
- INCRは存在しないキーを0として扱い、値を1増やした整数を返す。
- INCRは整数以外・先頭の+・不要な先頭ゼロ・符号付き64bit整数の範囲外をエラーとし、その際に値を変更しない。
- INCRで既存キーのTTLを維持する。
- 複数クライアントからのINCRで更新を取りこぼさない。
- TCPで分割されて届くリクエストと、一度に複数届くリクエストを処理する。
- 未知のコマンドや引数個数の誤りではエラー応答を返し、同じ接続で次の正しいコマンドを処理する。

永続化:
- --dataで指定したファイルに保存する。保存方式は自由。
- SIGTERMによる正常停止後、同じファイルで起動すると値と有効期限が復元される。
- 停止中も有効期限は経過する。再起動でTTLを延長しない。
- 起動時に既に期限切れのキーを復活させない。
- 強制終了時の耐久性は今回の対象外。

検証:
- 実際のTCP接続を使う統合テストを用意する。
- 分割受信、パイプライン、複数クライアント、バイナリ値、TTL、再起動をテストする。
- テストは一時ディレクトリと自動割り当てポートを使い、並列実行で衝突しないようにする。
- テストを実行し、失敗があれば原因を直して再実行する。
- サーバの処理を既存のRedisや外部DBへ委譲しない。
